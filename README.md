# Monty Bytecode Intepreter
A simple interpreter for Monty ByteCodes, a scripting language that uses
a stack to manipulate data

## Description
Monty 0.98 is a scripting laguage that is first compiled
into Monty bytecodes. It relies on a unique stack and a
set of instructions to manipulate data.

This project implements an interpreter that reads Monty bytecode files,
processes their instructins, and executes the corresponding operations.

## Requirements
    - Ubuntu 20.04 LTS or compatible Linux dist
    - GCC compiler
    - C standard library

## Supported Instructions
    - push
    - pall
    - pint
    - pop
    - swap
    - add
    - nop
